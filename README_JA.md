## なぜ作ったのか

era シリーズ（eraTW など）の口上シーンは、すでに大きな規模に達しています：  
2,000 を超える口上ファイル、9 万を超える関数。  
ところが作者の手元にある道具は、いまだにメモ帳と全文検索のまま。

その結果、こんなことが日常的に起きています：

- 関数名を一文字でも書き間違えると、**その口上は黙って動かなくなる**——  
  ゲーム内で誰も喋らないし、エラーも出ない。
- 「この台詞はいつ発火するのか」を知りたいだけなのに、  
  同名関数の山を全文検索で漁るはめに。
- 台詞を一行直すたび「ゲームを起動 → 該当状態まで進める → 目視確認」。  
  深い条件になると十数分の grinding。
- 文字コードはファイルごとにバラバラ。保存した瞬間に文字化け。

kojo-editor は、これらを「開けば分かる、直せば確かめられる」に変えます。

## できること

**🗂 構造化ブラウズ**  
ゲームディレクトリを開くと、口上ファイルはキャラクター別に整理され、  
関数は「キャラ → 家族 → 面」のツリーで展開。条件バッジがひと目で分かり、  
クリック一つで該当行へ。9 万を超える関数も、インデックスは数秒。

**🧭 条件マトリクス**  
プロジェクト全体を「状態・タイミング × イベント・面」のマトリクスに展開し、  
各セルに該当する関数の数を表示。セルをクリックすれば対応する口上関数へ直行できます。  
中日表記の切替、未分類の分離、仮想スクロールにより、10 万関数規模でも軽快です。

![条件マトリクス：キャラクターと状態・タイミングで展開し、セルから該当する口上関数へ](docs/assets/app-condition-matrix.jpg)

**✅ 書き間違いはその場で検出**  
関数名のタイプミス、家族の欠落、書式不一致——「規約チェック」パネルが  
問題をリストアップし、クリックで該当行へジャンプ。もう黙って壊れない。

**✍️ 「.kojo 言語」で書く**  
口上のために設計された日本語/中国語感覚の記述言語：  
`もし 好感度 ≤ 5：` といった語感で書けば、保存時にゲームがそのまま読める  
スクリプトへ自動コンパイル——元の文字コード・改行コードは一字も崩しません。  
書きたくない部分は元ファイルのまま手書きでも OK、両方の混在ができます。

**📖 構文一覧（付録）**  
`.kojo` の各記法について、必須項目・値・コンパイル結果・書き間違い時の警告を  
一枚の対応表に収録。チュートリアルのオーバーレイからそのまま参照できます。

![構文一覧：記法・必須・値・コンパイル結果・警告を並べて対照](docs/assets/app-syntax-reference.jpg)

**⌨️ VS Code のように自然な補完**  
ERB 命令、変数ファミリー、`#DIM` 宣言名、ユーザー関数、`$ラベル`、`.kojo` の原生領域を  
補完します。入力が止まるとポップアップし、遅延も調整可能。台詞・地の文・コメント行では  
邪魔をしません。定義ジャンプ、参照検索、リネーム、実引数のインラインヒント、  
シグネチャヘルプ、パンくず、折りたたみにも対応しています。

**▶ 状態リプレイ**  
セーブデータとキャラを選ぶと、全ての発火条件の真偽と分岐の行き先が  
一覧で表示されます。ゲームを回して状態を整える必要はもうありません。

**💉 状態インジェクション**  
好感度を特定の値に合わせてテストしたい？ **テスト用セーブ**に書き込みます——  
二段階確認・自動バックアップ・読み返し検証つき。実セーブとゲーム本体は常に読み取り専用。

**🛒 口上マーケット**  
口上パックと辞書パックをアプリ内で閲覧・インストール・更新。パッケージ名や作者で  
絞り込めます。公開ウィザードはワークスペースまたは通常の ZIP パックを受け取り、  
ローカルで事前検証してマーケット審査 PR を作成。作者側の GitHub 操作は不要です。

![口上マーケット：レジストリの閲覧、口上/辞書パックの導入、自分の作品の公開](docs/assets/app-market.jpg)

**🛡 データ安全と安定性**  
保存は書き込み許可領域とアトミック書き込みを経由。外部変更は三者マージに対応し、  
未保存のファイルを黙って上書きしません。操作単位の取り消し、ゴミ箱、バッチロールバックを  
常備。自動保存・クラッシュ復元・マルチルートワークスペース・タブ・分割編集で、  
長時間の作業でも進捗を失いにくくなっています。

## インストール

**Windows 10 / 11（x64）** — [Releases](https://github.com/Poboking/kojo-editor/releases/latest) からダウンロード：

- **インストーラー**：`kojo-editor_0.4.1_x64-setup.exe` をダブルクリックしてインストール。  
  以降は「設定 → 更新」から確認・更新できます。
- **ポータブル**：`kojo-editor_0.4.1_x64-portable.zip` を解凍してそのまま実行。  
  レジストリやスタートメニューには登録されません。更新は新しい zip をダウンロード  
  （Windows 11 は WebView2 ランタイム同梱。Windows 10 では別途導入が必要な場合があります）。

初回起動：ゲームディレクトリを選択 → 自動認識・インデックス → 完了。  
書き込み権限を承認しなくても、閲覧・チェック・リプレイはすべて読み取り専用で使えます。

## 開発

```bash
pnpm test               # 全テスト（機能プール + 計時プール、7700+ passed）
pnpm typecheck          # 型チェック（root + app の二重実行）
pnpm audit:decoupling   # 「すべてはプラグイン」設計の監査
pnpm --filter @kojo/app tauri dev   # デスクトップシェル（初回ビルド 20-30 分）
```

アーキテクチャは**すべてプラグイン**：コアはゲーム知識ゼロ。  
新しいゲームへの対応 = アダプタプラグインを一つ追加するだけ。  
詳細は [ARCHITECTURE.md](docs/ARCHITECTURE.md)、  
コントリビューションの流れは [AGENTS.md](AGENTS.md) をどうぞ。
