- [ ] **A5** 低频面板（归档 / 注入 / 回放 / 升糖 / 插件状态）收在**活动栏底部**入口

### 5.B 命令体系与新建向导（P2）

- [ ] **B1** `Ctrl+Shift+P`（或 `F1`）弹命令面板，可搜索并执行命令
- [ ] **B2** `Ctrl+P` 弹快速打开；输入文件名，**文件名命中列在路径命中之前**（含 Windows `\` 路径）
- [ ] **B3** 工具栏「新建口上文件」按钮打开向导（与 `Ctrl+N` 等价）
- [ ] **B4** 向导选 角色 / 家族 / 起始时机与编号，文件名**实时预览**
- [ ] **B5** 点「创建」落盘 `.kojo` 骨架并自动打开定位
- [ ] **B6** 只读态打开向导，**首屏即提示不可写**（不等落盘才报错）
- [ ] **B7** `Esc` 关闭 overlay（不改动文件）

### 5.C 多标签与编辑器深化（P3）

- [ ] **C1** 依次打开多个文件，标签栏累积；点击切换，**滚动/光标位置保留**
